How Tailscale works here:
Each service (ingestion, NLP, storage) runs on a separate machine. Tailscale connects them via a WireGuard mesh — no port forwarding, no static IPs. The dashboard calls peers by MagicDNS hostname, e.g. nlp-node.tail1ab2c.ts.net.

Traffic is end-to-end encrypted and access is controlled by an ACL policy — only authorised nodes can call each endpoint.
